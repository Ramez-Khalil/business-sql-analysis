# Business SQL Analysis

## Overview
This project demonstrates how SQL can be used to answer common business and operational questions using a simple relational database.

## What’s Included
- **Schema**: Table definitions for customers, products, orders, and order items
- **Sample Data**: Insert statements to populate the tables
- **Queries**: Business-focused SQL queries that generate actionable insights

## Folder Structure
- `schema/` – database table creation scripts
- `data/` – sample insert statements
- `queries/` – SQL queries answering business questions

## Example Business Questions Answered
- What is the total revenue generated from completed orders?
- How much revenue does each product generate?
- Which customers placed the most orders?
- What percentage of orders were returned?

## How to Use
1. Run `schema/create_tables.sql`
2. Run `data/insert_sample_data.sql`
3. Run `queries/business_questions.sql`

## Why This Project Matters
SQL is a core skill for CIS, analytics, and business intelligence roles. This project highlights practical database thinking and the ability to translate business questions into SQL queries.
